# Changelog

## 0.2.0

- Revised opt-in page layout with narrow, default and wide widths; responsive header and toolbar.
- Semantic surface, spacing, focus and outline tokens for all four themes.
- Revised ActionList with compact and aligned variants, optional media and separate actions.
- Existing panel extended with interactive and compact variants; responsive CardGrid, optional HeroCard.
- Status badges, compact and regular empty states, period navigation and native table primitives.
- Responsive component catalog, static contract tests and Chromium browser checks in the Pages pipeline.
- Existing public selectors and CSS entry points retained. No automatic consumer migrations.
